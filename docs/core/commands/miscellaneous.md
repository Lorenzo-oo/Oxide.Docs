# Miscellaneous Commands

## oxide.lang

**Usage:** `oxide.lang <two-letter language code>`  
**Aliases:** `o.lang`, `lang`

Sets the language to the specified language. Run from the server console it sets the **server** language; run by a player in chat it sets that **player's** language.

### Example `oxide.lang en`

```
Server language set to en
```

## oxide.save

**Usage:** `oxide.save`  
**Aliases:** `o.save`

Saves all data files.

### Example `oxide.save`

```
Saving Oxide data...
```

## oxide.version

**Usage:** `oxide.version`  
**Aliases:** `o.version`

Displays the Oxide version and branch.

```
Oxide.Rust Version: 2.0.6042
Oxide.Rust Branch: master
```
